# Штаб проекта — шаблон для Claude Code

Папка, в которой живёт весь контекст твоего проекта: решения, статус, процессы
по SIPOC+E, факты, звонки. Claude Code читает её и работает с тобой как человек,
который в курсе дела.

## Зачем это нужно

Обычный чат с моделью — как сотрудник, который каждое утро приходит с чистой
головой. Вчера вы час обсуждали проект, сегодня он ничего не помнит, и ты снова
объясняешь, кто клиент, что решили и где застряли. Через пару недель контекст
размазан по десяткам чатов, и найти, почему отказались от варианта Б, уже нельзя.

Штаб решает это просто: **контекст живёт в файлах, а не в переписке.** Файлы
переживают любую сессию, Claude читает их на старте и сам дописывает по ходу.

## Что это даёт

**Claude начинает с того места, где вы остановились.** Первым делом он читает
`STATE.md` и последние решения и одной фразой говорит, где проект. Не нужно
пересказывать — можно сразу работать.

**Записи ведутся без тебя.** Прозвучало «окей, делаем так» — Claude сам создаёт
файл решения. Сдвинулся срок или закрылась задача — сам обновляет статус.
Это прописано в `CLAUDE.md`, напоминать не нужно.

**Не ходишь по кругу.** В каждом решении есть поле «что отвергли и почему».
Через месяц, когда снова захочется вариант Б, ответ уже записан — вместе
с аргументом.

**Понятно, что автоматизировать и сколько это сэкономит.** Процесс разбирается
по SIPOC+E: кто поставляет, что на входе, какие шаги, кому результат и сколько
это стоит в часах сейчас. Узкое место видно на бумаге до того, как написана
первая строка кода, а цифра «было» позволяет потом честно показать «стало».

**Факты не превращаются в мифы.** Цифры, цены, условия лежат в `knowledge/`
с источником и датой. Звонки — в `calls/` с выжимкой сверху: о чём договорились,
что обещали, следующий шаг.

**Всё можно откатить и передать.** Штаб — обычная папка с текстовыми файлами
под git. Любую правку видно и можно вернуть. Нового человека в команде
вводишь в курс ссылкой на репозиторий, а не часовым созвоном.

**Никакой привязки к сервису.** Это markdown: читается в любом редакторе,
на GitHub, глазами. Не Notion и не чужая база — данные твои.

## Что внутри

| Где | Что там |
|---|---|
| `STATE.md` | Где мы сейчас: стадия, задачи, блокировки, ключевые цифры |
| `decisions/` | Лог решений: что решили, почему, что отвергли |
| `process/` | Карты процессов по SIPOC+E — что автоматизируем |
| `knowledge/` | Факты о рынке, клиентах, продукте — с источником |
| `calls/` | Транскрипты звонков с выжимкой сверху |
| `playbooks/` | Как делаем повторяющиеся вещи |
| `CLAUDE.md` | Правила для Claude: как вести записи и как себя вести |

Команды: `/brief` — где остановились, `/sipoc` — разобрать процесс, `/call` —
разобрать звонок, `/save` — зафиксировать решение, `/week` — итог недели.

Код агента в штабе не пишут. Штаб — для решений, планов и разборов,
агент живёт в отдельной папке.

## Как забрать себе

- **Через GitHub:** кнопка **Use this template** → **Create a new repository**
  (лучше приватный — там будут твои данные). Потом `git clone` к себе.
- **Без GitHub:** **Code** → **Download ZIP**, распаковать в отдельную папку.

Дальше — по шагам в [START-HERE.md](START-HERE.md). Первый запуск — минут 15.
