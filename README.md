# Штаб проекта — шаблон для Claude Code

Папка, в которой живёт весь контекст твоего проекта: решения, статус, процессы
по SIPOC+E, факты, звонки. Claude Code читает её и работает с тобой как человек,
который в курсе дела.

## Как забрать себе

- **Через GitHub:** кнопка **Use this template** → **Create a new repository**
  (лучше приватный — там будут твои данные). Потом `git clone` к себе.
- **Без GitHub:** **Code** → **Download ZIP**, распаковать в отдельную папку.

Дальше — по шагам в [START-HERE.md](START-HERE.md).
