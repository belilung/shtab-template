# Начни отсюда

Это шаблон штаба проекта. Штаб — папка, в которой живёт весь контекст
твоего проекта: решения, факты, процессы, звонки. Claude читает её
и работает с тобой как человек, который в курсе дела.

## Что сделать один раз (15 минут)

1. Claude Code у тебя уже стоит. Если нет: https://claude.com/product/claude-code
2. Распакуй этот архив в отдельную папку и переименуй её под свой проект
   (например `shtab-mybusiness`). Код агента здесь жить не будет —
   для него потом заведёшь отдельную папку.
3. Открой терминал в этой папке и выполни:

   ```
   git init
   git add .
   git commit -m "штаб создан"
   ```

   Это машина времени: любой файл можно будет откатить.

4. Запусти:

   ```
   claude
   ```

5. Напиши первую фразу:

   ```
   Прочитай CLAUDE.md. Раздел «О проекте» пустой — задай мне вопросы
   и заполни его.
   ```

Всё. Штаб живой.

## Как пользоваться дальше

| Команда | Что делает |
|---|---|
| `/brief` | «Где мы остановились» — сводка на старте сессии |
| `/sipoc` | Разобрать процесс по SIPOC+E и записать карту |
| `/call` | Разобрать звонок или встречу, записать выжимку |
| `/save` | Зафиксировать решение и обновить статус |
| `/week` | Итог недели: что сдвинулось, что застряло |
| `/homework` | Проверить домашку к субботе: что готово, чего не хватает |

## Домашка субботы 1 в штабе

1. Заполни «О проекте» в `CLAUDE.md` — первой фразой выше.
2. `/sipoc` — допиши свой процесс после разбора на экране. Появится файл в `process/` с цифрами E.
3. Пройди процесс руками один раз с таймером, впиши время по шагам.
   У кого цифры E уже есть — пропустить.
4. Сложи примеры в `process/<имя>/examples/`: 5–10 входов, 3–5 выходов.
5. `/homework` — проверь, что ничего не забыл. Кинь файл процесса в чат до четверга.

Колода первой субботы: https://bobai.tech/6weeks/1

Статусы и решения Claude пишет сам, без твоей просьбы — это прописано
в `CLAUDE.md`.

## Одна страховка

Длинную сессию заканчивай командой **`/save`** или фразой «зафиксируй и обнови
статус». Правило в `CLAUDE.md` модель может пропустить, команда — нет.

Если сессия закончилась без записи — считай, что её не было.

## Как сохранять изменения

Раз в день или после серьёзной сессии:

```
git add .
git commit -m "коротко что изменилось"
```

Можешь просто попросить Claude: «сделай коммит».
