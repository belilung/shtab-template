# Решение 0001 — ведём проект через штаб

- **Дата:** суббота 1 · 19.09.2026
- **Статус:** принято

## Вопрос
Где хранить контекст проекта, чтобы он не рассыпался по чатам и заметкам.

## Решение
Один git-репозиторий как штаб. Весь контекст живёт в файлах, Claude Code
работает поверх них.

## Почему
Контекст в переписке теряется при каждом новом чате. Файлы переживают
сессии, их видно, их можно откатить и передать другому человеку.

## Что отвергли и почему
- Notion / Google Docs — Claude не работает с ними как с рабочей памятью,
  каждый раз нужно вручную копировать.
- Держать в голове чата — при новой сессии всё начинается с нуля.

## Что теперь меняется
Каждое решение фиксируется здесь. Статус проекта живёт в STATE.md.
