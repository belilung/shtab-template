# Факты о проекте

Факты о проекте, которые должны пережить любую сессию.

Один файл — одна тема:
- `rynok.md` — рынок, объём, тренды
- `klienty.md` — портрет клиента, боли, возражения
- `konkurenty.md` — кто ещё это делает и чем берёт
- `produkt.md` — что продаём, цены, условия
- `komanda.md` — кто за что отвечает

Правило: каждый факт с источником и датой. Цифра без источника через месяц
превращается в миф, на который все ссылаются.

Что сюда НЕ кладут: мнения, идеи, планы. Планы живут в STATE.md,
идеи — в decisions/, когда становятся решениями.
