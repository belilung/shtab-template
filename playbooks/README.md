# Плейбуки

Как мы делаем повторяющиеся вещи: как готовимся к звонку, как отвечаем
на возражение по цене, как оформляем счёт.

Плейбук появляется по правилу третьего раза: если ты в третий раз
объясняешь Claude одно и то же — это не объяснение, это плейбук.
Скажи ему: «оформи это как плейбук», и он запишет файл сам.

Когда плейбуков станет больше пяти и они начнут срабатывать сами
по контексту — пора превращать их в скиллы. Это тема продвинутых недель.
