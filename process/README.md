# Процессы

Один процесс — один файл. Имя файла: `01-obrabotka-zayavok.md`.

Начинай не с «что бы автоматизировать», а с описания того, как есть
на самом деле. Половина узких мест видна уже на этапе описания.

Порядок заполнения на разборе: P → O → C → I → S → E. Команда `/sipoc` ведёт
именно так. Примеры лежат в папке с именем файла: `process/01-obrabotka-zayavok/examples/`.

Таблица «сейчас / хотим / стало» — это результат программы. Заполняй колонку «сейчас»
честно, даже если цифра стыдная. Без неё в конце нечего будет показать.

Заполненный пример — `_ПРИМЕР-pravki-klienta.md`: как выглядит процесс после `/sipoc`,
с цифрами в E, узким местом и открытыми вопросами.
